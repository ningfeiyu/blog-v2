> 原文：Julian Goldie《Best AI Agent Course For Beginners? My 8 Gentle Picks》，2026 年 10 月 13 日，agentos.guide。本文为翻译整理，保留原文的排名和说法，并加了必要的提醒。作者在文中明确说，前两名是他自己的社群和免费课程，排名带偏向；六家第三方课程他只读了官网页面，本人没有完整上过，价格和要求以 2026 年 10 月 13 日页面所示为准。

新手学 AI 智能体，最难的不是技术，是第一周别被吓退。作者给新手定的标准很具体：第一周不要求写代码，单节课要短到一次能看完，第一天就要跑通一个能干活的智能体或工作流，卡住了要有地方问。名气、深度、证书都重要，但第一周不重要。

他的结论先摆在前面：最好的新手课是他自己的付费社群 AI Profit Boardroom，理由是有从新手到专家的路线图、每周四次辅导电话、3400 多名成员可以问；免费起点是他自己的 AI Money Lab。下面六家是其他机构的课，按“第一周有多温和”排序，前六家第一周都不要求写代码，后两家要求会 Python。

## 三步快速上手

今天就能开始，不用装任何东西。第一，先把下面五个术语读到顺眼为止；第二，加入一个免费社群，比如作者的 AI Money Lab，有个能问问题的地方；第三，挑一门不用写代码的课，只上第一节，跑通一个东西就停。那一下跑通的时刻，智能体就从一个概念变成一个工具了。

## 五个术语，用大白话讲

| 词 | 大白话 | 在智能体系统里对应什么 |
| --- | --- | --- |
| 模型 | 大脑，负责读和写 | 每个模型单独配一份设置，换大脑不用重建 |
| 智能体 | 拿到目标后自己走步骤的模型 | 团队里一个工人，一人只干一件事 |
| 工具 | 智能体能用的东西，比如浏览器、文件夹 | 按智能体开关，只给它该碰的东西 |
| 技能 | 存下来的一套文字指令，专干一件事 | 存一次，哪个智能体需要就用哪个 |
| 记忆 | 智能体在多次会话之间留下的笔记 | 所有智能体共用一份记忆，事实一致 |

聊天机器人是答完就停，智能体是干完活才停。所谓智能体系统（Agent OS），就是一个仪表盘下面跑好几个智能体，共用一份记忆。

## 8 门课，一个一个说

### 1. AI Profit Boardroom

作者自己的付费社群，排名第一要带着偏向读。有新手到专家路线图，每周四次辅导电话，3400 多名成员，还有可安装的智能体系统。FatRank 在测了 27 个社群后把它评为第一。作者不承诺多久能做出第一个能干活的智能体，因为这取决于你投入的时间。

### 2. AI Money Lab

作者的免费课程和社群，付费之前先从这里开始，连他自己的付费社群也一样。只需要一个免费 Skool 账号就能加入。

### 3. Zapier Academy

Zapier 的免费培训站，页面说所有课程和学习路径都免费。多数课程 10 到 55 分钟，新手从 AI Builder 路径里的 Jumpstart 开始。页面说“从零到第一个 Zap 不到 20 分钟”，这是全部页面里唯一一个明确写出的上手时间。Zap 是工作流，还不是完整的智能体，算你的第一次胜利。

### 4. Anthropic Academy：Claude 101

在 Anthropic Academy 上标为免费，内容包括第一次对话、项目、技能、接工具。另一门《Claude Cowork 入门》也是免费的，有一节就叫“把第一个任务交给 Claude Cowork”，页面说这门课的设计目标是第一周就能真正干活。通过 Skilljar 注册，页面没列写代码要求。

### 5. n8n Quickstart

n8n Academy 上的课，页面说不需要写代码经验，但补充一句：懂一点接口和 JSON 会有帮助。先做简单工作流，再做一个客服聊天智能体。做智能体那部分需要一个 n8n 实例和一个聊天模型提供商的接口密钥。

### 6. 用 Microsoft Copilot Studio 创建智能体

Microsoft Learn 上的学习路径，共五个模块，标为新手级。前两个模块是“规划你的第一个智能体”和“在 Microsoft Copilot Studio 里创建你的第一个智能体”。页面说要完成练习，需要一个有授权用户的环境。

### 7. Microsoft：AI Agents for Beginners

GitHub 上的免费课，每课有文字课、短视频和 Python 代码示例。安装指南要求 Python 3.12 或更新版本，还要一个 Azure 账号。课程有 Discord 频道，学员可以在里面问问题。

### 8. Hugging Face：AI Agents Course

免费课，页面说能带你“从新手到专家”。前置要求是基础 Python 和基础的大模型知识。每章按一周、每周 3 到 4 小时设计。结课有结业证书，还有 Discord 学习小组。

## 一门新手课是怎么变成智能体系统的

一门课教你做出一个智能体，智能体系统是你把好几个这样的智能体组织起来之后的东西。作者给每个新手的四条规则是：先做一个只干一件事的智能体；先用免费模型，免费的拖后腿了再付费；每个模型单独配一份设置；朝着一个仪表盘、一份共享记忆去建。

他自己的智能体系统里跑着 Hermes、Claude、GLM、Kimi 等多个智能体，共用一份记忆。但他也说，第一周完全不需要这些，只需要一个能把一件事干好的智能体，剩下的都是同一个想法的重复。

## 你的前 7 天

这是作者给不会写代码的人排的计划，右边一栏是每天在养成的习惯。

| 天 | 做什么 | 在养成什么习惯 |
| --- | --- | --- |
| 1 | 学会五个术语，加入一个免费社群 | 动手之前先认清各个部件的名字 |
| 2 | 选一件小事，用一句话写下来 | 给每个智能体一个清晰的任务 |
| 3 | 上一门不用写代码的课的第一节，跑通一个东西 | 先让第一个智能体跑起来，再加第二个 |
| 4 | 接一个工具 | 一次只开一个工具 |
| 5 | 把指令存成一个技能 | 指令存一次，到处复用 |
| 6 | 把关于你和你工作的事实加进记忆 | 只留一份共享记忆 |
| 7 | 分享结果，问一个问题，再选下一门课 | 扩大之前先复盘 |

这一周别开始做第二个智能体。

## 新手常犯的错

- 没写过代码，第一门课却选了 Python 课。
- 一次报五门课，一门也没学完。
- 第一周就想搭一整支智能体队伍。
- 免费模型还没拖后腿，就先买了最贵的模型。
- 跳过术语，第二课就听不懂了。
- 明明社群一点就能问，却从来不问问题。
- 第一天就把所有工具都交给智能体。
- 不核对输出，直接信。

作者说，这些错的解法都一样：把第一周做得更小。

## 第一周之后去哪

想看所有级别的推荐，去作者的进阶榜单；想一直免费，去他的免费课文章；想要路线图、智能体系统和辅导电话里现场答疑，再考虑加入 AI Profit Boardroom。

## 常见问题

**新手学智能体课需要会写代码吗？** 不用。前六门课都没把写代码列为要求，n8n 的课明确说不需要写代码经验。微软 GitHub 那门和 Hugging Face 那门要求会 Python。

**新手多快能看到第一个成果？** 只有 Zapier Academy 的页面明确写了时间：从零到第一个 Zap 不到 20 分钟。作者不给自己的课承诺时间，因为取决于你投入的时间。

**五个术语是什么意思？** 模型是大脑，智能体是朝着目标干活的模型，工具是它能用的东西，技能是存下来的指令，记忆是多次会话之间留下的东西。

**免费的新手课有哪些？** 按 2026 年 10 月 13 日的页面：AI Money Lab、Zapier Academy、Claude 101、Hugging Face 的课都标为免费。微软 GitHub 那门也是免费的，但要求会 Python。

**一门新手课怎么通向智能体系统？** 一门课做出一个只干一件事的智能体，智能体系统是好几个这样的智能体放在一个仪表盘下，共用一份记忆，每个模型单独配一份设置。

## 结语

作者的收尾就三句话：学会五个词，做出一个只干一件事的智能体，遇到卡住先问一个问题再着急。第一个小胜利，比从榜单里挑哪个名字更重要。
