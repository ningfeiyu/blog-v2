知识—权力—自我：现代社会如何塑造人｜思想史与个人认知框架

2026年9月25日
#思想史
#福柯
#认知框架
#知识权力
#自我管理
#AI治理

一句鸡汤背后，藏着三百年的治理史

“性格决定命运。”

这句话你大概率听过不止一次。它出现在成功学书的腰封上，出现在领导谈话的收尾里，也出现在每个人深夜自我审判的念头中——错过那一轮浪潮，是不是因为我性格里有缺陷？不够果断，不够自律，不够狼性？

先说结论：**这句话不是定律，而是一种叙事。**性格当然会影响人生，但它从来不是唯一的因。把复杂的结构性问题——出身、时代、制度、资源、机会、运气——重新解释为个人品质问题，是现代社会最成功、也最不被察觉的话术之一。

真正值得研究的，不是这句话是谁发明的，而是它为什么能成为强大的现代叙事。要回答这个问题，得从两千五百年前说起，然后穿过工业革命、两次世界大战、改革开放，一直走到今天你手机里的推荐算法。

这条线索的名字，叫知识—权力—自我。

一、源头：从"性格即命运"到"性格造命运"

赫拉克利特有句话常被译为"人的性格就是他的命运"（ethos anthrōpō daimōn）。但注意原意：性格是命运——人活着的方式本身就是他的神谕，这是一种存在论的描述，不是成功学承诺。

现代流行语偷偷做了强化：命运主要由性格决定。两者完全不同。

这个偷换发生在19世纪。工业革命需要大量自律、勤奋、能自我管理的新型劳动力，而恰好，一套新的道德话语出现了：

  • **1859年，塞缪尔·斯迈尔斯《Self-Help》**出版，把自我教育、勤奋、节制、坚毅置于成功叙事的中心，卖出几十万册，影响了整整一代英美人的自我想象；
  • 马克斯·韦伯后来在《新教伦理与资本主义精神》里揭示了这场汇合：宗教的禁欲伦理褪去神学外壳后，变成了世俗的"职业人"道德——你不努力，不只是穷，还是"不道德"；
  • 20世纪心理学再接棒：人格测验、尽责性研究、自我效能感、成长型思维（growth mindset）、坚毅品格（grit）……“个人特质影响人生结果"获得了经验研究的外观。

心理学研究本身有真实的证据基础，这一点必须承认。值得警惕的是大众传播中那个三步逻辑跳跃：

人格与结果存在统计关联 → 成功主要因为人格优秀 → 失败主要因为人格有缺陷。

第一步是相关研究，第二步是夸大归因，第三步已经宣判了受害者的道德责任。一个下岗工人、一个错过风口的中年人、一个出身小镇的求职者，在这套叙事里都被悄悄判了刑：你混得不好，是因为你不够好。

要理解这个判决为什么会生效，需要进入十九世纪。

二、十九世纪：人开始被系统地"看见”

工业革命带来的不只是工厂，还有一整套让人口变得"可见"的技术：

人口普查、户口登记、义务教育、标准化考试、工厂考勤、军队体检、医院病历、犯罪档案……这些制度在18到19世纪像孢子一样在欧洲和北美同时萌发。

它们的初衷大多不是压迫——普查是为了征税和兵源，考试是为了选拔人才替代贵族世袭，病历是为了治病。客观上，它们极大提升了组织能力和公共治理水平，这是现代国家能力的来源，也是现代生活水准的高地的地基。

但它们同时生产了一种全新的东西：分类。

  • 正常 / 异常
  • 合格 / 不合格
  • 健康 / 疾病
  • 优秀 / 落后
  • 有效率 / 低效率

每个人第一次如此彻底地成为一个"可以被统计、比较、分类和管理的对象"。你在学校拿到分数，在工厂拿到工号，在军队拿到体检等级，在医院拿到诊断书——每一张纸都在告诉你：你是什么，你在分布曲线上的哪个位置。

福柯把这套机制叫规范化（normalization）：现代社会的权力不再主要靠砍头的暴力运作，而是靠"定义什么是正常人"来运作。你不需要被强迫，你只需要被测量，然后你会自己去够那个标准。

三、二十世纪：从行为管理到灵魂塑造

把这套现代治理技术用到极致的，是二十世纪的各种总体性体制——包括苏联和改革开放前的中国。

1949年后的中国是一个值得细看的样本：教育体系、单位制度、户籍制度、组织生活、政治学习，共同织成一张强大的社会组织之网。一个人从升学、就业、分房到迁户口，每一步都要经过组织的认定。到了文革时期，政治意识形态对专业秩序和教育秩序的介入达到顶点——知识的合法性不再由证据决定，而由立场决定。

这里必须避免两种简单化：

第一种简单化是"共产主义发明了控制"。不对。户籍、统计、档案、考核，全是现代国家治理的通用技术，各国都在用，只是浓度和配方不同。社会主义实验的特殊性在于：在现代行政能力之上，叠加了一套高度集中的意识形态与政治组织体系——它是现代治理技术与特定政治理想结合后的一个历史版本，而不是凭空冒出来的怪物。

第二种简单化是把这个版本一概斥为罪恶然后翻篇。更值得记下的是它的认识论教训：**当知识的生产、审查和定价权完全集中于一个机构时，“真理"与"权力"之间的距离就消失了。**这个教训在任何一个时代、任何一个社会都可能需要重新应用。

四、改革开放：从"革命人"到"市场人”

1978年以后，中国重新接入现代学术体系、市场经济和国际教育范式。社会评价的语言也随之换了一套：

革命觉悟、政治身份、成分、集体主义——这些词退居二线；教育、能力、竞争、效率、人力资本、个人发展——这些词走上台前。

很多人把这段变化讲成"从控制到自由"的单线故事。不准确。更准确的描述是：**治理逻辑和社会评价机制发生了重组。**评价你的主体从单位变成了市场，评价你的指标从政治表现变成了收入和职级。

于是一个新的主体形象被召唤出来，它的口号你每天都能听到：

“你应该主动成为更好的自己。”

自律、学习、情商、认知升级、执行力、个人品牌、财务自由——注意这套词汇的结构：它不再说"你必须服从"，也不说"你必须成为正确的人"，它说"你应该主动成为更好的自己"。

这套话语有真实的正面价值：它确实帮助无数人获得了真实的能力、开阔了视野、摆脱了身份束缚。我本人就是它的受益者之一。但当它被过度使用时，一个精妙的闭环出现了：结构性问题被重新包装为个人责任。

房价高？是你认知不够。行业消失？是你没有提前布局。三十岁还没成功？是你不够自律。你看，每一个需要社会学、经济学、政策层面解释的问题，最后都收口成了一句对你个人品格的质疑。

五、三阶段公式：治理技术的漫长转向

把三百年压缩成一行字，现代治理的演化线索是这样的：

“你必须服从我” → “你必须成为正确的人” → “你应该主动成为更好的自己”。

第一阶段靠暴力与禁令，成本高昂且容易激起反抗。第二阶段靠规范与测量，你开始自我规训。第三阶段最精妙：外部强制表面上减少了，但个体内部的自我监控急剧增加——

你每天早上自动查看打卡记录，为绩效分数心跳加速，刷到同龄人的成功立刻自我检视，把休息时间也称为"自我投资"，把焦虑当作上进心，把自己当作一家公司来经营。

福柯管这个叫治理术（governmentality）：权力最成功的形态，是让被治理者把治理者的目标当作自己的目标，然后自愿地、勤奋地、日复一日地执行它。执行者甚至心怀感激——“感谢这个平台让我成长”。

这不是阴谋，没有人坐在幕后设计它。它是无数制度、话语、商业激励在几百年里自发收敛出来的形态。这也是它难以察觉的原因：你找不到一个可以起诉的敌人。

六、关键刹车：不要把这个框架用成反智主义

读到这里，一个危险的滑坡就在眼前：既然知识背后都是权力，那是不是所有知识都是权力制造的骗局？心理学是骗人的，医学是骗人的，统计学是骗人的，专家全是御用的，不如去信朋友圈的"内部消息"？

大错特错。这是这个框架最常被用歪的地方，而且歪了之后正好落进另一种收割——民科、阴谋论、反疫苗、“觉醒人士"卖的课。

必须分清两件事：

  1. “知识会被权力使用”——这是事实。心理学被用于设计和操纵你的信息流，医学统计被药企资助扭曲过，经济学模型为激进市场化改革背书出过人命。这些都有扎实案例。
  2. “所有知识都是权力制造的”——这是阴谋论。心理学、医学、统计学、经济学各自有数百年的研究传统、公开的证据标准和激烈的内部争论。学科内部最激烈的批评者就在学科内部。知识也被用来限制权力、揭露错误政策、把瘟疫从城市里赶出去。

成熟的态度不是相信或否定某个学科，而是追问知识是如何生产出来的。这引出本文最实用的部分。

七、七个问题：普通人的知识审查框架

下次任何"科学结论"“权威报告"“专家建议"出现在你面前——尤其是那些试图定义你、评价你、给你的人生下判决的——过一遍这七个问题：

  1. **谁提出的？**提出者的训练背景、利益位置、发表场合是什么？
  2. **谁提供资金或制度支持？**资助方从结论中能获利吗？
  3. **数据从哪里来？样本是什么？**是随机对照，还是美国本科生的问卷，还是只跟踪了某个特定人群二十年？
  4. 谁可能从这个定义或分类中受益？“多动症"的定义变宽，受益的是谁？“35岁危机"的说法流行，卖课的受益的是谁？
  5. **这个命题是否允许被证伪？**有没有任何证据能让支持者说"我错了”？如果没有，那是信仰不是知识。
  6. 它是在描述现实，还是在规定"什么才算正常”？“内向者职场竞争力弱”——这是发现，还是把职场现状伪装成自然规律？
  7. **如果暂时拿掉权力关系，这个结论还成立吗？**疫苗有效性和药企公关是两回事；把药企拿掉，疫苗还在起效。把大厂绩效制度拿掉，“狼性"还剩什么？

这七个问题的目标不是制造阴谋论——恰恰相反，它的目标是建立**“证据 + 方法 + 权力结构"三层同时在线**的审查能力：看证据够不够硬，看方法站不站得住，再看它为谁服务。三层齐全，你既不盲从权威，也不滑向虚无。

八、换掉因果模型：性格决定你如何打牌

回到开头的"性格决定命运”。用它替换掉旧的单线模型：

不要再用：

性格 → 命运

改用这个：

环境 → 性格 → 行为 → 环境反馈 → 新的性格/行为 → 人生结果

并且把出身、时代、制度、资源、关系网络、机会和随机性，全部作为外部变量保留在模型里。

注意这是个循环而不是直线：你的性格被环境塑造，你的行为改变环境，环境反过来重塑你的性格。人是被喂养进一个反馈回路的，而不是拎着一份固定人格出厂的。

于是可以得到一句我认为比"性格决定命运"诚实得多、也有用得多的话：

性格决定你如何利用手里的牌，但性格并不决定你一开始拿到什么牌。

而且别忘了下一句：**“性格"本身也是发牌的一部分。**它由家庭、教育、阶层、同伴、职业经历和重大事件塑造。一个缺爱的孩子长成的谨慎，和一个被托举的孩子长成的自信，都不是"选"出来的。

对四十岁以后的人，这句话有直接的疗愈意义和直接的行动意义——

疗愈：不要因为错过了某个时代（移动互联网、比特币、直播），就把人生解释成"性格缺陷”。当年你没入场，首先因为你在什么样的信息环境、资源环境、社会环境里，其次才是选择问题。用当年的你的视角审判当年的你，是认知上不公正的事。

行动：牌已经发到手里了，抱怨牌不好没有出路——这句话也是真的，但它应该是复盘的最后一句，不是第一句。前一问应该是：**下一轮技术变革中，我如何建立更好的信息获取、实验和行动系统？**环境不可选，反馈回路里的行为是自己唯一持续握有的变量。

九、三百年全景：从被人观察到被人预测

把整条线索摊开在一张时间轴上：

工业革命 → 殖民主义与人口分类 → 学校/工厂/军队的标准化 → 人口统计与社会科学的诞生 → 二十世纪意识形态治理 → 冷战时期的知识与国家战略 → 改革开放与市场化治理 → 人力资本与自我管理 → 平台化社会 → 算法治理 → AI。

注意每一阶段"谁在观察人"的答案在变化：

  • 过去三百年：主要是国家在观察——普查、档案、成分、户籍；
  • 二十世纪中后期：企业和管理科学加入观察——绩效、测评、用户调研；
  • 2010年代起：平台开始持续记录每个人的行为——点击、停留、定位、支付，观察第一次变成24小时不间断；
  • 现在，AI：观察升级为预测、分类、推荐、劝导和自动决策。模型不仅知道你做了什么，还在推断你会做什么、想要什么、什么时候会崩溃、愿意为哪件商品多付五块钱。

问题正在从"谁定义正常人”，进一步进入**“谁拥有定义、预测和影响个人行为的模型”**。规范化曾经靠考试实现，如今靠推荐权重实现；当年的档案存在派出所，如今你的档案存在多家公司的特征库里——而且它比你更早知道你要买什么。

三百年前，一个人要被判"异常”，需要穿过一屋子专家的评估；今天，一个人在毫无察觉中被系统分类、定价和劝导，不需要任何专家见面。**塑造变得更高效，也更隐形。**这是思想史给AI时代的我们留下的最直接的作业。

十、收束：四条认知原则

折腾了这么多，最后落到四条可以贴在墙上的原则：

  1. 不把一切归因于个人。（防成功学驯化）
  2. 也不把一切归因于结构。（防虚无主义瘫软）
  3. 不把知识神圣化。（防权威崇拜）
  4. 也不把知识阴谋论化。（防反智收割）

四条合起来，是一种同时看见个人能动性、结构约束、知识生产机制、权力关系的思考能力。它比寻找"幕后集团"更有解释力，也更重要的一点是：**它保护你的现实行动空间。**阴谋论者的终点是瘫痪——“都是安排好的”；成功学信徒的终点也是瘫痪——“都是我的错”。而这个框架的终点是：看清哪些牌是发的，哪些牌是打的，然后继续打牌。

写这篇的目的从来不是证明"社会在控制我们”——那只是又一种廉价的爽文叙事。目的是建立一点认知免疫力：当下一句"你该成为更好的自己"出现时，你能同时听见它的三层声音——它可能是真知，可能是生意，也可能是治理术在你脑内的回声。分清了，才谈得上选择哪句值得听。

三百年前人开始被统计，一百年前人开始被测评，十年前人开始被记录，今天人开始被预测。下一章是什么，没人知道。但至少下一次，当一个定义你的声音出现时——

先问那七个问题，再决定要不要把它当成自己。
